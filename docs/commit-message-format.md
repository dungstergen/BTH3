# Commit Message Format De Nop Giang Vien

## Format tieu de commit

Dung mot dong tieu de theo mau:

`[Issue-<1|2>][Bai-<01..08>] test(black-box): <noi dung ngan gon>`

Vi du:

`[Issue-1][Bai-03] test(black-box): du lieu hop le cho giai PT bac 2`

## Format mo ta commit (body)

```
Muc tieu:
- <tom tat muc tieu cua commit>

Pham vi:
- Bai toan: <ten bai>
- Issue: <1 hoac 2>

Test case:
- <danh sach ID test case>

Files:
- <file 1>
- <file 2>

Kiem tra:
- npm test
```
